Tutorial

Installation

DiamaneOS includes Auditor with the app ID de.diamaneos.auditor. It is built from the DiamaneOS Auditor source and updated with the OS.

Remote verification

This service checks a phone on a schedule and can email you when the phone does not send a valid check in time.

  1. Create an account on this site.
  2. Open this site on the phone, log in and tap Add this phone. Auditor opens and asks you to confirm the account.
  3. Instead of the button, you can select "Enable remote verification" in the Auditor menu and scan the QR code shown for your account on another device.
  4. Set an alert email address under Configuration to receive alerts.
  5. Reload the account page to see the first result.

First pairing not verified by hardware

On some phones the device maker cannot vouch for the first pairing. Auditor then asks you to confirm how the phone was set up. Only continue if you trust how it was set up. The account page and alert emails label these phones "First pairing not verified by hardware".

The first pairing must exactly match an official DiamaneOS release. Every later check is hardware attestation pinned to that first pairing.

A new phone of this kind waits for your approval on the account page. If the account has an alert email address, you get an email with the phone's details. The phone is not monitored until you approve it. Reject it if you did not add it yourself. An account can have up to three phones waiting.

A pairing can be flagged for review, for example when the phone answered faster than a real phone can. A flag does not reject the pairing, but check that you added the phone yourself before approving it. Once approved, every failed check from the phone raises an alert.

After a reset

A factory reset erases Auditor's key, so the phone must be paired again. It then appears as a new device.

When the old record stops checking in after a newer device joined the account, the account page and an email ask whether the old phone was reset. If it was, retire the old record. A retired record raises no alerts and its checks are refused. It stays until it expires like any inactive device.

Local verification

Auditor can also check a phone from a second phone running the DiamaneOS Auditor, without this service. Attestation explained describes both ways and what a result can establish.
